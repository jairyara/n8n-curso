## Fundamentos del Intercambio de Datos en la Web

### ¿Qué es JSON?

**JSON** (*JavaScript Object Notation*) es el formato estándar universal que utilizan las aplicaciones para comunicarse entre sí a través de internet. Es liviano, fácil de interpretar tanto por humanos como por computadoras, y organiza los datos en pares de **clave** y **valor**.

```json
{
  "id": 1042,
  "cliente": "Laura Sánchez",
  "monto": 1750.50,
  "es_vip": true,
  "productos": ["Licencia n8n", "Consultoría IA"]
}
```

En n8n, absolutamente toda la información que fluye entre un nodo y otro viaja empacada en estructuras JSON. Cada nodo entrega un arreglo de objetos JSON en su salida para que el siguiente nodo los consuma.

---

### ¿Qué es una API?

Una **API** (*Application Programming Interface*) es el puente de comunicación entre dos sistemas independientes. 

> **La analogía del restaurante:**
> Tú eres el cliente sentado en la mesa (tu flujo de n8n) y la cocina es el servidor donde están los datos (Google, Telegram, Shopify). Tú no puedes entrar directamente a la cocina a preparar los platos; necesitas al **mesero**, quien toma tu orden, va a la cocina, trae los alimentos y te los sirve organizados en la mesa. La API es exactamente ese mesero.

#### Métodos Principales: GET vs POST

1. **Método GET (Pedir información al mesero):**
   Envías una solicitud para consultar datos sin modificar nada en el servidor remoto.
   ```http
   GET https://dummyjson.com/carts
   ```
   *Respuesta devuelta por la API:* Un objeto JSON con la lista de carritos y facturas.

2. **Método POST (Entregar datos al mesero para que haga algo):**
   Envías un paquete de información (*payload*) para crear o modificar un recurso en el servidor de destino.
   ```http
   POST https://api.telegram.org/bot<TOKEN>/sendMessage
   Content-Type: application/json

   {
     "chat_id": "987654321",
     "text": "¡Alerta! Se ha registrado una compra VIP superior a $1,500 USD."
   }
   ```

## Nodos Avanzados de Transformación en n8n

### 1. Nodo Switch (El Clasificador de Correspondencia)
Cuando las decisiones tienen más de dos salidas posibles (más allá del simple Sí/No del IF), el nodo **Switch** permite definir múltiples compuertas de enrutamiento basadas en reglas de comparación (números, cadenas, expresiones regulares).

### 2. Nodo Split Out (Desempacar la Maleta)
A menudo, una API entrega una lista entera de elementos agrupada dentro de un único campo (*Array*). Si queremos que n8n procese cada elemento como un registro independiente, el nodo **Split Out** (*Item Lists*) "abre la maleta" y convierte ese bloque en filas individuales.

### 3. Nodo Merge (El Punto de Encuentro)
Cuando un flujo se bifurca en varios caminos o cuando necesitamos combinar datos provenientes de dos fuentes distintas (por ejemplo, clientes de un CRM y facturas de un ERP), el nodo **Merge** actúa como la glorieta que vuelve a unificar los datos en una sola autopista de información.

### 4. Nodo HTTP Request (El Teléfono Universal)
Cuando una plataforma no cuenta con un nodo nativo preconstruido en n8n, el **HTTP Request** permite conectarse a cualquier servicio del planeta que cuente con una API REST o GraphQL.

### 5. Nodo Loop Over Items (La Cadena de Producción)
Permite procesar colecciones de datos elemento por elemento en lotes controlados, evitando saturar APIs externas y gestionando límites de tasa (*rate limits*).

## Configuración Guiada del Flujo Avanzado

```text
[Schedule Trigger] ➔ [HTTP Request] ➔ [Split Out (carts)] ➔ [Switch]
                                                               ├──> [Ruta < 1500]  ──┐
                                                               └──> [Ruta >= 1500] ──┴─> [Merge] ➔ [Loop Over Items]
```

### Paso 1: El Temporizador (Schedule Trigger)
- **Intervalo:** Diario (*Daily*).
- **Hora de Ejecución:** `7:00 AM`.

### Paso 2: La Extracción (HTTP Request)
- **Método:** `GET`.
- **URL:** `https://dummyjson.com/carts`.

### Paso 3: Desempacar Facturas (Split Out)
- **Campo a desempacar:** `carts`.
- *Resultado:* Convierte 1 paquete masivo en 30 ítems individuales procesables.

### Paso 4: Clasificación por Monto (Switch)
- **Tipo de Dato:** `Number`.
- **Valor a evaluar:** `{{ $json.total }}`.
- **Ruta 1:** Menor que `1500` (Compras regulares).
- **Ruta 2:** Mayor o igual que `1500` (Compras VIP de alto valor).

### Paso 5: Unificación (Merge)
- **Modo:** `Append` (Acumular y preservar todos los registros).
- Conectar ambas salidas del Switch a las entradas del Merge.

### Paso 6: Procesamiento en Bucle (Loop Over Items)
- Conectar la salida VIP para despachar avisos individuales y cerrar el ciclo conectando la acción de regreso al puerto de bucle.
